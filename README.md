# EduAdvisor API

## Project Overview

EduAdvisor API is a Full Stack Academic Advisory System developed using FastAPI, SQLite, HTML, CSS, and JavaScript.

The system helps students receive course recommendations based on their interests, academic profile, and completed courses.

## Features

* User Registration
* User Login with JWT Authentication
* Student Profile Management
* Course Management
* Academic History Tracking
* API-Based Course Recommendations
* Interactive Dashboard

## Technology Stack

### Frontend

* HTML
* CSS
* JavaScript

### Backend

* FastAPI
* SQLAlchemy
* JWT Authentication

### Database

* SQLite
